# Spring Backend Travel Agency

## Overview
This is a Java Spring Boot back-end application for a travel agency checkout system. 
It demonstrates object-oriented design, MySQL integration, REST API development, and service implementation for an Angular front-end.

## Features
- REST API for processing customer orders
- Entity classes and enums for customers, carts, and vacations
- Repository interfaces for database access using Spring Data JPA
- Services for order processing and purchase responses
- Input validation for front-end data
- Sample customers added programmatically
- Stores data in MySQL

## Technologies
- Java, Spring Boot (Data JPA, Data REST)
- MySQL
- Lombok
- IntelliJ IDEA
- Angular (front-end)
- Git / GitLab

## Setup
1. Clone the repo:
2. Open in IntelliJ IDEA
3. Configure MySQL and update application.properties
4. Run the Spring Boot application
5. Use the Angular front-end to test checkout functionality
